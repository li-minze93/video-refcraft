# video-refcraft

看一条参考视频，拆成以后还能调用的动效卡、转场卡和声音卡。

你不需要会描述动效。把视频丢过来，说「照这个做」就够了。这个 skill 负责看懂画面怎么动，写成可复用的卡，存在你自己的电脑上。口播成片仍由 `video-talkcraft` 来做。

## 它做什么

- 从一条参考视频里拆出可复用的画面动效，做成能在 Remotion 里播放的卡片。
- 同一种动效只建一张卡。这条视频里用了几次，记在镜头记录里，不复制出多张几乎一样的卡。
- 转场单独成卡，不写进画面卡里面。
- 听得清、能分开的点击、弹出、划过声，才做成音效卡，并记下配哪一张画面。
- 每张卡可以在 Remotion Studio 里单独预览。默认一张卡一个画面。
- 卡登记进本地库之后，`video-talkcraft` 做新视频时可以按名字调用。调用时只换标题、条目、颜色和素材，不改原来的时序、缓动、比例和层级。

## 它不做什么

- 不从零做口播成片。那是 `video-talkcraft`。
- 不做没有参考视频的产品宣传片。
- 整段都是口播、听不出单独音效时，不编音效卡。
- 不把这些卡改写成 Talkcraft 原来的模板卡。它们是从参考视频里新拆出来的。

## 怎么用

在 Codex 里装好这个 skill 之后，丢一条参考视频，然后说：

> 用 video-refcraft 看这条视频，把里面的动效、转场和音效拆成以后能调用的卡。

视频可以是本地文件，也可以是链接。给链接时，会先把整段下载下来再分析，不是只在浏览器里跳着看。

做完后打开 Remotion Studio 给你看。确认这张卡像不像参考视频。不会擅自渲染成一条成片。

## 卡存在哪里

可调用的卡写在你的电脑上：

`~/.codex/skills/video-refcraft/library/`

- `library/index.json`：总目录。Talkcraft 按这里的 `id` 找卡。
- `library/cards/`：每张卡的 Remotion 实现。
- `library/sources/<来源>/reference.cards.json`：这条视频的哪一镜用了哪张卡。

这个仓库保存 skill 的用法和目前已经拆好的卡，用来查看和备份。以后新拆的卡仍然先落在你的电脑上。

卡的名字描述画面怎么动，不描述它从哪条视频来。英文 ID 用短横线，例如 `stagger-step-row`。中文名给人看，例如「错峰步骤排」。

这些卡来自一条口播参考。

这条参考的声音是一整段口播，没有单独的点击或划过声，所以还没有音效卡。
